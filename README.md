
# 🏛️ Stellarium Planner

> **برنامه‌ریز جامع روزانه کنکور سراسری — ویرایش ۳.۲**

یک سیستم ایزوله، مینیمال و بدون وابستگی (Zero-Dependency Single-File Web App) برای مدیریت زمان، ردیابی جلسات مطالعه، تایمر فوکوس و آنالیز پیشرفت داوطلبان کنکور سراسری با طراحی نئوکلاسیک و آکادمیک.

🔗 **[نسخه آنلاین](https://stellarclientplanner16.github.io/stellarium-planner/)**

---

## 📐 فلسفه طراحی

Stellarium Planner با هدف **حذف اصطکاک** اجرای برنامه‌های سنگین مطالعاتی توسعه یافته است. هیچ فریم‌ورک سنگین، موتور رندر خارجی یا درخواست شبکه اضافه ندارد. تمام محاسبات، ذخیره‌سازی و مدیریت تایمر به صورت **کاملاً ایزوله در مرورگر** پردازش می‌شود.

```
┌─────────────────────────────────────────────────────────────────┐
│                    Stellarium Execution Engine                   │
├────────────────────────────┬────────────────────────────────────┤
│  Core Modules              │  UI & Aesthetics                   │
│  ├── Dynamic Timeline Calc │  ├── CSS Variable Palette Engine   │
│  ├── Multi-Day State       │  ├── Responsive Layout & Grid      │
│  ├── Session & Focus Timer │  ├── 5 Premium Color Themes        │
│  └── LocalStorage Persists │  └── Print Engine Optimization     │
└────────────────────────────┴────────────────────────────────────┘
```

## 🔥 ویژگی‌های کلیدی

### 📅 برنامه‌ریزی هفتگی
- **۷ تب روزانه** — هر روز هفته برنامه مستقل دارد
- **ذخیره خودکار** در LocalStorage — بدون نیاز به سرور
- **بازنشانی** برنامه هر روز یا بازنشانی کامل

### ⏱️ تایمر فوکوس
- **تایمر جلسه مطالعه** — شروع، توقف و بازنشانی
- **حالت فوکوس تمام‌صفحه** — حذف حواس‌پرتی
- **نوار پیشرفت** — نمایش بصری باقی‌مانده زمان

### 🎨 ۵ پالت رنگی پریمیوم

| تم | حالت روشن | حالت تاریک |
|----|-----------|-----------|
| ☕ **آکادمیا** | بژ کلاسیک | مشکی گرم |
| 🌲 **زمردی** | سبز مخملی | سبز تیره |
| 🌊 **سورمه‌ای** | آبی ملایم | سرمه‌ای عمیق |
| 🔮 **بنفش** | بنفش پاستلی | بنفش نئونی |

### 📊 پیشرفت و آمار
- **نوار پیشرفت** روزانه با درصد
- **شمارش معکوس** تا کنکور (روز، ساعت، دقیقه، ثانیه)
- **آمار مطالعه** — مجموع ساعات مطالعه هر روز

### 📝 لقمه (یادداشت سریع)
- اضافه کردن یادداشت‌های کوتاه
- تیک زدن و حذف لقمه‌ها
- حداکثر ۲۲۰ نمایش در لیست

### 🔗 دسترسی سریع
- **لینک‌های سفارشی** به سایت‌های مطالعاتی
- **مدیریت لینک‌ها** — افزودن، ویرایش و حذف
- **۱۰ لینک پیش‌فرض** به پلتفرم‌های آموزشی

### 🖨️ خروجی چاپ
- بهینه‌سازی شده برای **چاپ A4 افقی**
- حذف خودکار عناصر غیرضروری

## 🏗️ معماری فنی

### ساختار فایل
```
stellarium-planner/
├── index.html      ← اپلیکیشن کامل (فقط یک فایل!)
├── README.md       ← این فایل
└── LICENSE         ← مجوز MIT
```

### وابستگی‌ها
- **هیچ فریم‌ورک JS** — Vanilla JavaScript خالص
- **فونت Samim** — از CDN (فقط فونت فارسی)
- **بدون Backend** — تمام منطق در مرورگر

### ذخیره‌سازی
```
localStorage Keys:
├── stellarium_schedule_v4_{day}    ← برنامه هر روز
├── stellarium_checks_v4_{day}      ← وضعیت تیک‌ها
├── stellarium_start_time_v4_{day}  ← ساعت شروع
├── stellarium_notes_v3             ← لقمه‌ها
├── stellarium_mode_v3              ← حالت شب/روز
├── stellarium_palette_v3           ← پالت رنگی
└── stellarium_quick_links_v1       ← لینک‌های سریع
```

## 📖 راهنمای استفاده

### ۱. تنظیم ساعت شروع
در سایدبار سمت راست، ساعت شروع روز رو تنظیم کنید (پیش‌فرض: ۰۵:۰۰).
دکمه‌های میانبر: `05:00` | `05:30` | `06:00` | `07:00`

### ۲. افزودن پارت مطالعه
روی دکمه **`+ افزودن پارت`** کلیک کنید:
- **عنوان** — نام درس یا فعالیت
- **مدت زمان** — به دقیقه
- **نوع** — اختصاصی (با چک‌باکس) یا استراحت (بدون چک‌باکس)
- **جزئیات** — توضیحات تکمیلی

### ۳. استفاده از تایمر فوکوس
- روی دکمه **▶** کنار هر پارت کلیک کنید
- تایمر در سایدبار فعال میشه
- برای حالت تمام‌صفحه، دکمه **🎯 فوکوس** رو بزنید

### ۴. ردیابی پیشرفت
- هر پارت تموم شده رو **تیک** بزنید
- نوار پیشرفت و درصد رو ببینید
- شمارش معکوس تا کنکور به صورت زنده آپدیت میشه

### ۵. مدیریت لینک‌های سریع
- روی **⚙️** کنار Quick Access کلیک کنید
- لینک‌های دلخواه رو اضافه یا ویرایش کنید

## 🛠️ شخصی‌سازی

### تغییر دروس پیش‌فرض
فایل `index.html` رو باز کنید و آرایه `defaultRows` رو ویرایش کنید:
```javascript
var defaultRows = [
  {id:1, duration:35, title:"🌅 بیداری", details:"توضیحات", checkbox:false},
  {id:2, duration:100, title:"📚 حسابان", details:"تست‌زنی", checkbox:true},
  // ...
];
```

### تغییر لینک‌های پیش‌فرض
آرایه `defaultLinks` رو ویرایش کنید:
```javascript
var defaultLinks = [
  {label:"درس من", url:"https://example.com"},
  // ...
];
```

### تغییر هدف کنکور
عدسی `data-countdown-date` در HTML رو تغییر بدید (فرمت: `YYYY-MM-DD`).
