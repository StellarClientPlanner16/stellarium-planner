## 📖 درباره پروژه (Overview)

**Stellarium Planner** یک اپلیکیشن تک‌فایلی (Single-File Web App) کاملاً ایزوله و بدون نیاز به سرور است که با هدف بهینه‌سازی حداکثری بهره‌وری مطالعاتی طراحی شده است. این ابزار بر پایه فلسفه **Dark Academia & Minimalist Eleganza** ساخته شده و تلفیقی از مدیریت زمان پویا، سیستم پومودورو، تولیدکننده صوت‌های محیطی (Ambient Noise Synthesizer) و لینک‌های دسترسی سریع را در یک واسط کاربری متمرکز ارائه می‌دهد.

---

## ✨ ویژگی‌های کلیدی (Key Features)

### ⏱️ موتور زمان‌بندی پویا (Dynamic Schedule Engine)
* **محاسبه خودکار زنجیره زمان:** با تغییر زمان شروع روز (مثلاً ۰۵:۰۰ یا ۰۷:۰۰)، تمامی پارت‌های روزانه به‌صورت خودکار مجدداً زمان‌بندی می‌شوند.
* **مدیریت کاملاً تعاملی:** قابلیت افزودن، ویرایش، حذف، جابه‌جایی پارت‌ها (▲/▼) و ویرایش درون‌خطی (In-line Editing) توضیحات.
* **تفکیک هوشمند پارت‌ها:** جداسازی پارت‌های مطالعاتی (دارای چک‌باکس و تأثیر در پیشرفت) از پارت‌های استراحت[cite: 4].

### 🎧 موتور صوت‌درمانی و سنتز صوتی (Web Audio Soundscape)
* **سنتز صوتی اختصاصی:** تولید نویزهای محیطی به‌صورت الگوریتمی (بدون نیاز به دانلود فایل صوتی):
  * ⚪ **White Noise** (نویز سفید جهت قطع صداهای محیطی)[cite: 4]
  * 🟤 **Brown Noise** (نویز قهوه‌ای عمیق برای آرامش ذهن)[cite: 4]
  * 🌧️ **Rain Sound** (صدای باران با فیلتر Low-pass)[cite: 4]
  * 🔥 **Fire Cracking** (صدای سوختن چوب و جرقه به‌صورت تصادفی)[cite: 4]
  * 🧠 **Binaural Beats (40Hz)** (ضربان بینورال موج گاما جهت افزایش تمرکز و حافظه کارآمد)[cite: 4]
* **میکسر چندکاناله:** کنترل مستقل حجم صدای هر کانال صوتی[cite: 4].
* **پلیر یوتیوب یکپارچه:** امکان استریم ویدیوها و موزیک‌های Lofi مستقیم از یوتیوب[cite: 4].

### 🎯 تایمر پومودورو پیشرفته (Focus Pomodoro)
* **سیستم چرخه هوشمند:** مدیریت دورهای تمرکز، استراحت کوتاه و استراحت طولانی[cite: 4].
* **دکمه‌های دسترسی سریع:** تنظیم آنی زمان تمرکز (15m, 25m, 45m, 60m)[cite: 4].
* **هشدار صوتی (Beep Synthesizer):** اعلام پایان زمان تمرکز با تولید تن صوتی آکوستیک[cite: 4].

### 🎨 تم‌ها و شخصی‌سازی ظاهری
* **۴ پالت رنگی اختصاصی:** آکادمیا (Classic)، زمردی (Velvet)، سورمه‌ای (Indigo)، بنفش (Neon)[cite: 4].
* **حالت روز و شب (Dark/Light Mode):** سوئیچ کامل تم‌ها با حفظ کنتراست استاندارد[cite: 4].
* **پشتیبانی کامل از چاپ (Print Friendly):** استایل‌دهی اختصاصی جهت خروجی A4 افقی بدون المان‌های اضافی[cite: 4].

### 📝 مدیریت یادداشت‌های سریع (Loqme) & Quick Access
* **سیستم لقمه:** ثبت، علامت‌گذاری و حذف یادداشت‌ها و تکالیف سریع daily[cite: 4].
* **داشبورد لینک‌ها:** مدیریت و سفارشی‌سازی کامل دکمه‌های دسترسی سریع به وب‌سایت‌ها و پنل‌های کاری[cite: 4].

## 🛠️ معماری و تکنولوژی‌ها (Tech Stack)

پروژه بدون استفاده از هیچ‌گونه فریمورک سنگین خارجی توسعه یافته تا حداکثر سرعت اجرا و کمترین میزان مصرف حافظه (Zero Dependencies) تضمین شود[cite: 4]:

| بخش | تکنولوژی / ابزار | توضیحات |
| :--- | :--- | :--- |
| **UI / Markup** | HTML5 (Semantic) | ساختار استاندارد و دسترسی‌پذیر[cite: 4] |
| **Styling** | Pure CSS3 (Variables) | مدیریت تم‌ها با CSS Variables و انیمیشن‌های 60fps[cite: 4] |
| **Logic** | Vanilla JavaScript (ES6+) | معماری ایزوله بدون کتابخانه خارجی[cite: 4] |
| **Audio Engine** | Web Audio API | سنتز الگوریتمی امواج صوتی و نویزها[cite: 4] |
| **Storage** | Browser `localStorage` | ذخیره‌سازی کاملاً آفلاین و امن داده‌ها در مرورگر[cite: 4] |
