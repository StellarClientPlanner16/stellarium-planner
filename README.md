# 🌌 Stellarium Planner v3.0

> **Daily Study Gazette & High-Performance Focus Dashboard**
> یک برنامه‌ریز روزانه آفلاین، صفر-وابستگی (Zero-Dependency) و کاملاً واکنش‌گرا که بر پایه فریم‌ورک‌های طراحی **Dark Academia** و **Minimalist Eleganza** برای داوطلبان کنکور سراسری ریاضی (۱۴۰۵ / ۱۴۰۶) و دانش‌پژوهان توسعه یافته است.

## 📸 نمای کلی (Overview)

`Stellarium Planner` یک اپلیکیشن تک‌فایلی (`Single-File HTML Web App`) است که تمام محاسبات، مدیریت داده‌ها، سنتز صدا و زمان‌بندی را مستقیماً درون مرورگر انجام می‌دهد. نیازی به نصب هیچ پکیج، سرور یا اتصالات خارجی ندارد و داده‌های کاربر را کاملاً محلی (Local-First) ذخیره می‌کند.

---

## ✨ ویژگی‌های کلیدی (Key Features)

### 1. ⏳ موتور زمان‌بندی پویا (Dynamic Schedule Engine)
- **محاسبه خودکار زنجیره زمانی:** با تغییر «ساعت شروع روز» (مثلاً `05:00` یا `07:00`)، تمام پارت‌های مطالعه، استراحت‌ها و روتین‌های روزانه به صورت اتوماتیک دوباره زمان‌بندی می‌شوند.
- **تفکیک هوشمند پارت‌ها:** امکان تعریف پارت‌های **مطالعاتی/اختصاصی** (همراه با چک‌باکس پیشرفت) و پارت‌های **استراحت/روتین** (بدون چک‌باکس).
- **ویرایش و جا‌به‌جایی زنده:** جابه‌جایی پارت‌ها با دکمه‌های بالا/پایین (`▲` / `▼`)، ویرایش در لحظه توضیحات (In-place Editing) و مدیریت کامل پارت‌ها.

### 2. ⏱️ پومودورو پیشرفته و سریع (Advanced Pomodoro Timer)
- **تایمر اختصاصی با مدست‌سازی دورها:** پشتیبانی از حالت‌های `Work`، `Short Break` و `Long Break` همراه با نشانگرهای بصری دورهای تکمیل‌شده.
- **پیش‌تنظیم‌های سریع (Quick Presets):** سوییچ لحظه‌ای بین زمان‌های استاندارد مطالعه (۱۵، ۲۵، ۴۵ و ۶۰ دقیقه).
- **هشدار صوتی (Alert Beep):** اعلام پایان پارت تمرکز با استفاده از Web Audio API (بدون نیاز به فایل صوتی external).

### 3. 🔊 موتور سنتز صوت‌درمانی و نویز مَپ (Web Audio Synthesizer)
بدون نیاز به دانلود هیچ فایل MP3 یا اتصالات اینترنتی، مرورگر مستقیماً فرکانس‌ها و صوت‌های زیر را سنتز می‌کند:
- ⚪ **White Noise:** نویز سفید برای بلوک کردن صداهای محیطی.
- 🟤 **Brown Noise (Deep Noise):** نویز عمیق فرکانس پایین مناسب تمرکز سنگین.
- 🌧️ **Rain Simulation:** شبیه‌سازی صدای باران با فیلتر اکتیو Pink Noise.
- 🔥 **Cozy Fireplace:** صدای آتش و هیزم همراه با سیستم تولید Crackle اتفاقی.
- 🧠 **40Hz Binaural Beats (Gamma Waves):** ضربان بینورال گاما (ترکیب ۲۰۰ هرتز و ۲۴۰ هرتز) جهت افزایش حدت ذهن و تمرکز عمیق.
- **میکسر صدا (Volume Slider):** کنترل سطح صدای مستقل برای هر فرکانس و امکان ترکیب همزمان آن‌ها.
- 📺 **YouTube Ambient Embed:** امکان استریم زنده موزیک یا لوفای از یوتیوب مستقیماً درون پومودورو.

### 4. 🎨 سیستم تم و پالت رنگی (Theme & Palette Architecture)
- **پشتیبانی از Dark Mode / Light Mode:** سوییچ روان بین حالت روز و شب با نگاشت متغیرهای CSS.
- **۴ پالت رنگی حرفه‌ای:**
  - ☕ **Classic Dark Academia** (تِم اصلی آکادمیک و متین)
  - 🌲 **Emerald Velvet** (سبز زمردی و طلایی)
  - 🌊 **Indigo Teal** (سورمه‌ای و آبی عمیق)
  - 🔮 **Neon Violet** (بنفش آکادمیک مدرن)

### 5. 📊 آمار پیشرفت و شمارش معکوس کنکور (Analytics & Countdown)
- **محاسبه هوشمند ساعت مطالعه:** نمایش مجموع ساعات مطالعه مفید تکمیل‌شده در روز به صورت اعشاری.
- **نوار پیشرفت درصد:** محاسبه لحظه‌ای درصد پیشرفت روزانه بر اساس پارت‌های علامت‌خورده.
- **روزشماری دقیق (Target Countdown):** شمارش معکوس زنده روز، ساعت، دقیقه و ثانیه تا کنکور تیرماه ۱۴۰۶.

### 6. 📝 سیستم «لقمه‌ها» و دسترسی سریع (Loqme & Quick Links)
- **دفترچه یادداشت کوچک (Loqme):** ثبت نکات سریع، To-Doهای روزانه یا یادآوری‌های کوتاه با قابلیت تیک زدن و حذف.
- **دسترسی سریع (Quick Access):** لینک‌دهی مستقیم به پنل درس‌های اختصاصی (حسابان، فیزیک، شیمی، هندسه، گسسته)، NotebookLM و Roadmapهای توسعه مهارت.

## 🛠️ تکنولوژی‌ها و معماری (Tech Stack)

| لایه / بخش | تکنولوژی |
| :--- | :--- |
| **فریم‌ورک / ساختار** | HTML5 (Vanilla / Zero-Framework) |
| **استایل‌دهی و انیمیشن** | CSS3 (Custom Properties, CSS Grid, Flexbox, Transitions) |
| **فونت** | Samim Font (`dist/font-face.css`) |
| **موتور صوت** | Web Audio API (`AudioContext`, `BiquadFilterNode`, `OscillatorNode`) |
| **ذخیره‌سازی داده** | Web Storage API (`localStorage`) |
| **خروجی چاپ** | CSS `@media print` (پشتیبانی کامل از Landscape A4 بدون دکمه‌های اضافه) |

## 🚀 راهنمای اجرا (Getting Started)

هیچ مراحل نصب یا کانفیگی لازم نیست!

1. فایل `stellarium_3.html` را دانلود کنید.
2. آن را درون هر مرورگر مدرنی (Chrome, Firefox, Edge, Safari) باز کنید (`Double Click` یا `Drag & Drop`).
3. برنامه آماده استفاده است. تمام تغییرات شما به صورت خودکار در مرورگر ذخیره می‌شوند.

## 🖨️ قابلیت چاپ (Print-Ready Layout)

با فشردن کلیدهای `Ctrl + P` (یا `Cmd + P`)، استایل هوشمند چاپ فعال می‌شود:
- حذف تمامی المان‌های کنترلی، تایمر پومودورو و سایدربار.
- تنظیم افقی جدول بر روی کاغذ **A4 Landscape**.
- بهینه‌سازی کنتراست رنگ‌ها برای چاپ تمیز روی کاغذ.
